# Gebauer Swiss Automobiles

Website für Gebauer Swiss Automobiles (Ronny Gebauer, Widnau): Beschaffung von Luxusautos aus der Schweiz mit Lieferung bis vor die Haustür.

- Eine statische Seite (`index.html`), keine Build-Schritte.
- Sprachen: EN, DE, UK, PL, RO, SR.
- Bestellungen: Standard ist `ORDER_MODE = 'mailto'` (oben im Script). Auf Netlify `ORDER_MODE = 'netlify'` setzen, dann kommt jede Bestellung über Netlify Forms per E-Mail.
- Bilder liegen in `img/`.
